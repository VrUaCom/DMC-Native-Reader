# main.2 — до опрацювання

Ця гілка зберігає повний стан `main` на commit `10d9b7542a597a8e2dec13d6127ab4872a7cd294` перед архітектурним очищенням Native Reader 1.0.

Статус: **до опрацювання / legacy-format backlog**.

У цій гілці залишені старі та перехідні reader/parser paths, які не входять у чистий Architecture v2 baseline. Вони зберігаються як робочий backlog і джерело для подальшої канонічної міграції, але не повинні повертатися в `main` без переходу на canonical `dmc-rengine-cpp` authority.

`main` після цього snapshot має містити тільки чистий Native Reader baseline для MOD, SCM, DDS і PTX плюс generic Architecture v2 infrastructure.
