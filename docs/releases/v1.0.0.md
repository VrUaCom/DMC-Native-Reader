# DMC Native Reader v1.0.0

DMC Native Reader v1.0.0 is the first stable release of the clean Architecture v2 Android reader.

## Supported formats

The production registry is intentionally limited to four promoted families:

- **MOD** — native 3D model scene + typed inspection;
- **SCM** — native scene/model rendering + hierarchy/transform inspection;
- **DDS** — bounded DMC3 texture validation + image preview;
- **PTX** — bounded texture bundle + validated DDS child resources.

Unknown and unpromoted formats fail closed.

## Architecture guarantees

- C++20 native reader path;
- four-entry `NativeModuleRegistry`;
- no wildcard structural decoder;
- no Java-owned MOD/SCM binary parser;
- generic JNI session and capability-driven UI;
- malformed/unsupported inputs fail closed;
- read-only source-file handling.

## Notes for users upgrading from development APKs

Historical internal/debug APKs used a different signing authority. Android may require uninstalling a development build before installing the production-signed v1.0.0 APK.

Future official v1.x updates must remain signed by the pinned production authority.
