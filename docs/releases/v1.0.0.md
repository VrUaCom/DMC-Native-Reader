## Supported formats

The production registry is intentionally limited to four promoted families:

- **MOD** — native 3D model scene + typed hierarchy/skin/material inspection;
- **SCM** — native scene/model rendering + hierarchy/transform/material-state inspection;
- **DDS** — bounded DMC3 DXT1/DXT5 validation + image preview;
- **PTX** — bounded texture bundle + validated/navigable DDS child resources.

Unknown and unpromoted formats fail closed.

## Architecture guarantees

- C++20 native resource path;
- exactly four production modules: MOD / SCM / DDS / PTX;
- canonical DMC Rengine authority for promoted MOD/SCM semantics;
- no wildcard structural decoder;
- no platform-UI-owned binary parser;
- generic native Session and capability-driven UI;
- generic `RenderScene`, `InspectionDocument`, `ImagePreview` and `ChildResource` contracts;
- malformed/unsupported inputs fail closed;
- read-only source-file handling;
- no retired pre-v1 format modules in the production registry.

## Device acceptance

The accepted v1 Samsung/device path includes:

- MOD render, rotate/zoom, wireframe, hierarchy/skeleton and Inspector;
- SCM render, hierarchy and Inspector;
- standalone DDS image preview;
- PTX texture gallery with real DDS thumbnails;
- PTX -> DDS child preview;
- explicit child -> parent navigation;
- unsupported/malformed resources fail closed without stale geometry.

## Upgrading from development APKs

Historical internal/debug APKs used a different signing authority. Android may require uninstalling a development build before installing the production-signed v1.0.0 APK.

Future official v1.x updates must remain signed by the pinned production authority.

## Ecosystem

DMC Rengine is the central decompilation/reimplementation engine and C++20 modding foundation. Native Reader is the viewing/accessibility product built on that foundation; Pocket GDS covers broader resource-management and authoring workflows.

The long-term Native Reader direction is Android / iOS / Windows / Web with one central C++20 semantic authority. The Web path is intended to use WebAssembly rather than reimplementing DMC format semantics in JavaScript/TypeScript.
