# Скрипти дій: ефекти й видимі частини моделей (що треба, 2026-11-20)

Запит: коли грає дія (MotionScript), мають спрацьовувати її ефекти, а частини
моделі — з'являтися й ховатися, як у грі: кулька Jester, кисті Данте (з мечем /
вільна рука), волосся тощо.

## Що вже є в ядрі

- MotionScript: банки й дії, опкод 01 (який MOT грати), 03 (стан зброї: точка
  кріплення меча — спина / права / ліва рука), сигнали каналів (CEm034, Lady).
- 1584 з 1606 анімацій і 974 з 996 дій скриптів грають (див. `EFFECTS_GAP.md`).
- HID (покадрова видимість вузлів) — лише розпізнається й показується в Info;
  у паках персонажів його майже немає (em032: 2 файли), основна маса — катсцени.

## Що кажуть наявні специфікації (Clean-Room-Specs / Dirty room)

- `03_animation_motion.md` §5.2: опкоди скрипту — рух, стан зброї, вікна
  скасування, атаки й хітбокси. **Подій «ефект» у скрипті немає**: ефекти
  запускає код класу.
- `03` §7: HID — формат і програвання описані повністю (видимість вузла,
  ключі big-endian). Це можна реалізувати за специфікацією.
- `18_bosses.md` §8: Jester (em037) — «об'єкти-частини (7 видів зі своїми
  контролерами)», м'яч — окрема сутність (HP 10000). Коли й де вони
  з'являються — **[ГІПОТЕЗА]**, правил немає.
- Кисті Данте (стиснута / з мечем / розкрита), зміна волосся: правил у
  специфікаціях немає.

## Що треба дослідити (реверс), по одному пункту на специфікацію

1. **Ефекти дій.** Для гравця й кожного ворога / боса: яка дія (банк, дія)
   на якому кадрі запускає який ефект (вид, id, банк: власний /
   `static_effect.pac`), до якого вузла кріпиться, коли зупиняється.
2. **Видимість частин гравця.** Які MOD-частини / об'єкти моделі Данте
   (pl000 слот 1 і слот 12, інші костюми) показуються залежно від стану
   зброї (опкод 03), стилю, дії: кисті (вільна / стиснута / тримає меч),
   волосся, плащ.
3. **Об'єкти-частини ворогів.** Jester (em037): 7 видів об'єктів і м'яч —
   яка дія їх створює, з якої моделі (слот), де, як довго; те саме для інших
   босів зі «снарядами й об'єктами-частинами» (em025, em028, …).
4. **HID у грі.** Які дії / MOT грають HID-треки (em032) і як файл HID
   прив'язаний до MOT.

За правилом clean room (`AGENT_PROMPT.md`, розділ 2) пункти 1–4 пише той,
хто дивиться код гри; реалізацію за ними — той, хто його не бачив.
